# Donation-Tracking

A basic donation tracking dashboard built with HTML, CSS, and JavaScript using Chart.js.

## Features

- Displays total donations received and number of donors
- Interactive line chart showing cumulative donation trends
- Bar chart for monthly donation totals
- Table listing all donations
- Add new donations dynamically
- Filter donations by donor name and date range
- Dark mode toggle
- Export donations to CSV

## Live Demo

View the live dashboard at: [https://pavan-folder.github.io/Donation-Tracking/](https://pavan-folder.github.io/Donation-Tracking/)

## Usage

Open `index.html` in a web browser to view the dashboard.
